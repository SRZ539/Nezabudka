# Публикация Незабудки

## Что подготовлено

Это отдельная чистая копия исходников. Код приложения и бинарные шрифты не изменены.
История Git исходного архива не включена: исходная рабочая папка остаётся у вас.
В README добавлены скриншот, авторство, благодарности и указания по сборке.
Добавлены THIRD_PARTY_NOTICES.md и уведомление Adobe из метаданных самого шрифта.
Программа здесь не запускалась и не пересобиралась; проверена упаковка исходников.

## Загрузка через GitHub Desktop

1. Распакуйте Nezabudka из ZIP в новую папку. Не заменяйте ею единственную рабочую копию.
2. Откройте GitHub Desktop и войдите в свой аккаунт.
3. File → Add local repository → выберите распакованную папку Nezabudka.
4. Если Desktop сообщает, что это не Git-репозиторий, нажмите предложенную ссылку Create a repository here. Проверьте, что путь указывает именно на папку с README.md и src. Не создавайте вложенную пустую папку. Автоматическое создание README и лицензии не требуется.
5. Если остались изменения, в Summary напишите Initial release: Nezabudka alpha 0.1 и нажмите Commit to main (или имя текущей ветки).
6. Publish repository → имя Nezabudka → описание: «Локальный блокнот для Windows с напоминаниями, темами и тремя языками».
7. Для публичной публикации снимите Keep this code private и нажмите Publish repository.
8. На сайте в корне должны быть README.md, src, tests, tools, Nezabudka.slnx и остальные файлы, а не один ZIP/RAR.

Инструкция GitHub: https://docs.github.com/en/desktop/adding-and-cloning-repositories/adding-an-existing-project-to-github-using-github-desktop

## Готовая программа в Releases

1. В подготовленной папке на Windows выполните команду dotnet publish из README (нужен .NET 10 SDK). Так сборка получит дополненное уведомление Adobe.
2. Запустите результат и проверьте сохранение после перезапуска, напоминание в трее и переключение языков.
3. В PowerShell из корня проекта выполните:

```powershell
Compress-Archive -Path artifacts/nezabudka-win-x64/* -DestinationPath artifacts/Nezabudka-0.2.0-alpha-win-x64.zip
```

4. GitHub → репозиторий → Releases → Draft a new release / Create a new release.
5. Создайте тег `v0.2.0-alpha` на опубликованной ветке. Заголовок: `Незабудка 0.2.0 Alpha`.
6. Прикрепите ZIP готовой программы и отметьте This is a pre-release, затем опубликуйте релиз.

Пример описания релиза:

Локальный блокнот для Windows x64. Закрепление заметок, переносимый архив, резервные копии, выбор папки данных, глобальные горячие клавиши, три языка и калькулятор со вставкой в позицию курсора. Распакуйте `Nezabudka-0.2.0-alpha-win-x64.zip` целиком и запустите `Nezabudka.exe`. Это ранняя версия; об ошибках сообщайте в Issues.

Инструкция GitHub: https://docs.github.com/en/repositories/releasing-projects-on-github/managing-releases-in-a-repository
